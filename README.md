# Арбитражный калькулятор и исторический сканнер

Расчёт межбиржевого арбитража по реальному стакану плюс надстройка,
которая накапливает историю котировок CEX и DEX, ищет по ней связки
`USDT → … → USDT` и строит график произведения курсов во времени.

## Что внутри

| Раздел | Что делает |
|---|---|
| **Калькулятор** | чистая прибыль сделки A→B по реальным стаканам: проскальзывание по VWAP, комиссии бирж, вывод в сети, точки безубыточности |
| **Сбор котировок** | состояние накопленной истории: глубина, свежесть, покрытие по площадкам |
| **Связки по истории** | таблица циклов USDT → … → USDT по марже и график выбранной связки |
| **Монитор спредов** | живой поиск разницы цен между площадками с учётом комиссий |

## Запуск локально

```bash
pip install -r requirements.txt
python selftest.py              # проверить доступность источников
python -m history.collector     # сбор данных (отдельное окно, не закрывать)
streamlit run app.py            # интерфейс
```

Сборщик и интерфейс — разные процессы: сбор идёт, даже когда браузер закрыт.

## Чего этот инструмент не делает

История не позволяет торговать. Её ценность в другом: увидеть, как часто
возникает спред по конкретной связке, сколько он живёт и какие пары
структурно стоят внимания. На BNB Chain всё, что видно на минутной истории,
забирают MEV-боты в том же блоке — это инструмент аналитики и отбора пар,
а не торговый сигнал.

Межбиржевой спред по акциям и металлам на бесплатных данных получить нельзя:
публичные фиды консолидированные и с задержкой 15 минут. Адаптеры под них
в мониторе — заготовки под платный источник.
