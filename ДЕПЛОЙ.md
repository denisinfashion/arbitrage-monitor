# Публикация в интернет

Инструкция на два варианта: бесплатный и платный. Начните с бесплатного —
переезд на платный делается за десять минут и ничего переписывать не нужно.

---

## Вариант 1. Бесплатно: Streamlit Cloud + GitHub Actions

Приложение крутится на Streamlit Community Cloud, а сбор данных — в GitHub
Actions по расписанию. Обе площадки бесплатные, карта не нужна.

### Почему именно так

Streamlit Community Cloud запускает **один** процесс и стирает диск при
перезапуске, поэтому фоновый сборщик там жить не может — история не
переживёт ни одной перезагрузки. Решение: сбор вынесен в GitHub Actions,
результат публикуется одним сжатым файлом в Release, приложение читает
его по постоянной ссылке.

Побочный плюс: посетители страниц истории и связок вообще не обращаются
к внешним API — они читают готовый файл. Квоту GeckoTerminal посторонние
выжечь не смогут.

### Что заработает, а что нет

| | |
|---|---|
| DEX на BNB Chain, история и связки | работает полностью |
| OKX, Gate, MEXC, KuCoin | работают |
| **Binance, Bybit** | **отвалятся: 451** — серверы GitHub и Streamlit стоят в США |
| Монитор спредов | работает, но опрашивает биржи по запросу пользователя |

Если Binance принципиально нужен — это Вариант 2.

### Шаг 1. Репозиторий

Создайте на GitHub **публичный** репозиторий (у публичных бесплатные
минуты Actions не ограничены) и залейте туда содержимое папки:

```bash
cd "путь/к/arb_calculator"
git init
git add .
git commit -m "Арбитражный калькулятор с историческим сканнером"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/arb-calculator.git
git push -u origin main
```

Файл `.gitignore` уже настроен: база, снимки и журналы в репозиторий
не попадут.

### Шаг 2. Первый сбор

1. Вкладка **Actions** → согласиться на запуск workflow, если GitHub спросит.
2. Слева выбрать задачу **«Сбор котировок»** → **Run workflow**.
3. Прогон идёт минут десять. По завершении в разделе **Releases** появится
   тег `data` с файлами `history.parquet` и `pools.parquet`.

Дальше сбор пойдёт сам каждые 15 минут.

### Шаг 3. Приложение

1. Зайти на [share.streamlit.io](https://share.streamlit.io) под своим GitHub.
2. **New app** → выбрать репозиторий, ветку `main`, главный файл `app.py`.
3. До нажатия Deploy открыть **Advanced settings → Secrets** и вставить:

```toml
snapshot_url = "https://github.com/ВАШ_ЛОГИН/arb-calculator/releases/download/data/history.parquet"
```

4. **Deploy**. Через пару минут приложение откроется по адресу вида
   `https://ваш-логин-arb-calculator.streamlit.app`.

Именно наличие `snapshot_url` переключает приложение в облачный режим:
без него оно ищет локальную базу, с ним — читает снимок по ссылке.

### Что стоит знать про бесплатный тариф

- **Сон.** Приложение засыпает после 12 часов без посетителей. Первый заход
  после сна занимает полминуты — это нормально, данные не теряются:
  их собирает GitHub, а не приложение.
- **Память.** Около 1 ГБ. Приложение само снижает потолки в облачном режиме:
  до 40 активов и окно 12 часов по умолчанию. Если увидите сообщение
  про размер сетки — уменьшите окно или число активов.
- **Расписание Actions.** GitHub задерживает запуски под нагрузкой и
  **отключает расписание после 60 дней без коммитов** в репозиторий.
  Раз в пару месяцев делайте любой коммит, либо включите себе напоминание.
- **Скорость сбора.** За один прогон раннер работает 8 минут. Полная глубина
  в 7 дней по DEX наберётся за несколько часов работы расписания, а не сразу.

## Вариант 2. Свой сервер: всё без ограничений

Нужен, если хотите Binance и Bybit, круглосуточную работу без сна и полную
глубину истории. Подойдёт любой VPS в Европе от €4 в месяц.

```bash
# на сервере
git clone https://github.com/ВАШ_ЛОГИН/arb-calculator.git
cd arb-calculator
docker compose up -d
```

Всё: `docker-compose.yml` поднимает два контейнера — приложение и сборщик —
с общим томом под базу. Никаких снимков и GitHub Actions не нужно, сборщик
пишет напрямую.

Проверить, что идёт:

```bash
docker compose logs -f collector
```

Приложение будет на `http://IP-сервера:8501`. Для домена и HTTPS поставьте
перед ним Caddy или nginx — Caddy сам получит сертификат:

```
arb.вашдомен.ru {
    reverse_proxy localhost:8501
}
```

Если публикуете на свой сервер — **отключите workflow сбора** в GitHub
(Actions → «Сбор котировок» → ⋯ → Disable workflow), иначе два сборщика
будут дублировать запросы к биржам.

## Настройка охвата

Всё в `history/config.py`, класс `Settings`. В облаке те же параметры
задаются ключами запуска в `.github/workflows/collect.yml`:

```yaml
python cloud_collect.py --minutes 8 --days 7 --timeframe 1m --pools 100
```

Список бирж переопределяется переменной окружения там же, без правки кода:

```yaml
env:
  ARB_CEX_VENUES: "okx,gate,mexc,kucoin"
```

## Про открытый доступ

Приложение опубликовано без пароля, как и договаривались. Что это значит
на практике:

- страницы **истории и связок** посторонним ничего не стоят — они читают
  готовый файл, к биржам не ходят;
- страница **монитора** опрашивает биржи в момент запроса пользователя.
  Массовые заходы могут привести к временным ограничениям со стороны бирж
  по IP. Кэш на 15 секунд это сглаживает, но не отменяет.

Если понадобится закрыть — самый простой способ добавить пароль:

```python
# в начале app.py
import streamlit as st
if st.secrets.get("app_password"):
    if st.session_state.get("auth") is not True:
        pwd = st.text_input("Пароль", type="password")
        if pwd and pwd == st.secrets["app_password"]:
            st.session_state.auth = True
            st.rerun()
        st.stop()
```

и завести `app_password` в секретах Streamlit.

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| «Снимок пока пуст или недоступен» | Первый прогон Actions ещё не закончился, либо ссылка в секретах с опечаткой. Проверьте, что Release `data` создан и файл открывается по ссылке в браузере. |
| «Свежих данных нет уже N минут» | Прогон Actions упал или расписание отключено за неактивностью репозитория. Смотрите вкладку Actions. |
| В таблице нет Binance и Bybit | Ожидаемо: 451 из США. Это Вариант 2. |
| Сообщение про размер сетки | Уменьшите окно анализа или число активов в боковой панели. |
| Приложение долго открывается | Проснулось после 12 часов простоя. Разовая задержка. |
| Связок не находится | Обычный результат: на ликвидных парах спред меньше комиссий. Снизьте порог маржи, расширьте окно, добавьте площадки. |

## Проверки перед публикацией

```bash
python selftest.py                      # доступность источников с этой машины
python -m history.tests.test_math       # математика
python -m history.tests.test_pipeline   # сквозной прогон
python -m history.tests.test_snapshot   # перенос истории снимком
```

Первые три гоняются автоматически на каждый push — workflow «Проверки».
